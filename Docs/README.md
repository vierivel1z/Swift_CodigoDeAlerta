## Cómo mantener esta carpeta

- Actualizar el informe vigente y la matriz antes de crear otro reporte equivalente.
- Registrar sesiones breves en el Kanban o en el changelog; evitar un Markdown nuevo por cada corrección pequeña.
- Guardar resultados antiguos en Archive. No borrar créditos, fuentes de investigación ni README/recibos asociados a capturas.
- Los documentos de Archive y las auditorías fechadas conservan afirmaciones de su momento; no usarlas como estado actual ni como autorización para publicar.
