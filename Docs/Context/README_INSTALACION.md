# Cómo colocar este paquete en el proyecto Unity

1. Abre la carpeta del proyecto Unity que contiene `Assets/`, `Packages/` y `ProjectSettings/`.
2. Conserva los seis documentos base `.md` en `Docs/Context/`. Esta es su ubicación actual; no es necesario duplicarlos en la raíz.
3. Abre esa carpeta completa en tu IDE (Cursor, VS Code, etc.).
4. En el chat del IDE pega el contenido de `IDE_START_PROMPT.md`, o indícale que lo lea.
5. La primera tarea del IDE debe ser inspeccionar el proyecto y verificar su pipeline, NO generar un proyecto nuevo dentro de otro.
6. Si el profesor confirma detalles específicos del escenario 5, incorpóralos antes de implementar la lógica completa.

Importante: este paquete contiene **planes y contexto**, no un proyecto Unity ya programado.
